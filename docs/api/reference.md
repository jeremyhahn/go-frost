## Core Types

### Identifier

```go
type Identifier uint32
```

Represents a unique participant identifier. Must be non-zero.

### Configuration

```go
type Configuration struct {
    MinSigners uint32      // Minimum number of participants required to sign (threshold)
    MaxSigners uint32      // Maximum number of participants in the group
    Group      group.Group // Prime-order group implementation
}
```

Holds the FROST protocol configuration.

**Requirements:**
- `MinSigners >= 2`
- `MinSigners <= MaxSigners`
- `Group` must not be nil

### KeyPackage

```go
type KeyPackage struct {
    Identifier         Identifier          // Identifier of the participant
    SecretShare        group.Scalar        // Participant's secret key share
    GroupPublicKey     group.Element       // Group's public key
    VerificationShares []VerificationShare // All participants' verification shares
}
```

Contains all key material for a participant. Should be stored securely.

### SigningCommitments

```go
type SigningCommitments struct {
    Identifier             Identifier    // Identifier of the participant
    HidingNonceCommitment  group.Element // Commitment to the hiding nonce
    BindingNonceCommitment group.Element // Commitment to the binding nonce
}
```

Commitments generated by a participant during round one of signing.

### SigningNonces

```go
type SigningNonces struct {
    HidingNonce  group.Scalar       // Secret hiding nonce
    BindingNonce group.Scalar       // Secret binding nonce
    Commitments  SigningCommitments // Corresponding public commitments
}
```

Secret nonces generated by a participant during round one. Must never be reused.

### SignatureShare

```go
type SignatureShare struct {
    Identifier     Identifier   // Identifier of the participant
    SignatureShare group.Scalar // Participant's signature share value
}
```

A participant's signature share generated during round two.

### Signature

```go
type Signature struct {
    R group.Element // Group commitment point
    Z group.Scalar  // Aggregated signature scalar
}
```

A complete FROST threshold signature.

## Service Layer

### FrostService Interface

The main service interface for FROST operations.

```go
type FrostService interface {
    GenerateKeys(config Configuration, participantIDs []Identifier) ([]KeyPackage, group.Element, error)
    Sign(keyPackages []KeyPackage, msg []byte) (Signature, error)
    Verify(msg []byte, signature Signature, publicKey group.Element) error
    VerifyKeyShare(keyPackage KeyPackage) error
    GetCiphersuite() ciphersuite.Ciphersuite
}
```

#### NewFrostService

```go
func NewFrostService(suite ciphersuite.Ciphersuite) FrostService
```

Creates a new FROST service with the specified ciphersuite.

**Example:**
```go
suite := ristretto255_sha512.New()
service := service.NewFrostService(suite)
```

#### GenerateKeys

```go
GenerateKeys(config Configuration, participantIDs []Identifier) ([]KeyPackage, group.Element, error)
```

Generates key shares for participants using a trusted dealer.

**Parameters:**
- `config`: FROST configuration (min/max signers, group)
- `participantIDs`: List of participant identifiers (length must equal MaxSigners)

**Returns:**
- `[]KeyPackage`: Key packages for each participant
- `group.Element`: The group's public key
- `error`: Error if key generation fails

**Errors:**
- `ErrInvalidThreshold`: Invalid threshold configuration
- `ErrInvalidParameters`: Invalid participant IDs
- `ErrDuplicateParticipant`: Duplicate participant IDs

**Example:**
```go
config := frost.Configuration{
    MinSigners: 2,
    MaxSigners: 3,
    Group:      suite.Group(),
}
participantIDs := []frost.Identifier{1, 2, 3}
keyPackages, groupPubKey, err := service.GenerateKeys(config, participantIDs)
```

#### Sign

```go
Sign(keyPackages []KeyPackage, msg []byte) (Signature, error)
```

Generates a FROST threshold signature. Orchestrates the complete two-round signing protocol.

**Parameters:**
- `keyPackages`: Key packages for signing participants (length >= MinSigners)
- `msg`: The message to sign

**Returns:**
- `Signature`: The FROST threshold signature
- `error`: Error if signing fails

**Errors:**
- `ErrInsufficientParticipants`: Not enough participants
- `ErrInvalidKeyShare`: Invalid key package
- `ErrDuplicateParticipant`: Duplicate participant in key packages
- `ErrInvalidSignature`: Signature generation failed

**Example:**
```go
signingParticipants := []frost.KeyPackage{keyPackages[0], keyPackages[1]}
signature, err := service.Sign(signingParticipants, message)
```

#### Verify

```go
Verify(msg []byte, signature Signature, publicKey group.Element) error
```

Verifies a FROST signature.

**Parameters:**
- `msg`: The message that was signed
- `signature`: The signature to verify
- `publicKey`: The group's public key

**Returns:**
- `error`: nil if verification succeeds, error otherwise

**Errors:**
- `ErrInvalidSignature`: Signature verification failed
- `ErrInvalidParameters`: Invalid parameters

**Example:**
```go
err := service.Verify(message, signature, groupPublicKey)
if err != nil {
    log.Fatal("Verification failed")
}
```

#### VerifyKeyShare

```go
VerifyKeyShare(keyPackage KeyPackage) error
```

Verifies a participant's key share using verification shares.

**Parameters:**
- `keyPackage`: The key package to verify

**Returns:**
- `error`: nil if verification succeeds, error otherwise

**Errors:**
- `ErrInvalidKeyShare`: Key share verification failed

**Example:**
```go
for _, pkg := range keyPackages {
    if err := service.VerifyKeyShare(pkg); err != nil {
        log.Printf("Key share verification failed: %v", err)
    }
}
```

## Ciphersuite

### Ciphersuite Interface

```go
type Ciphersuite interface {
    ID() string
    Name() string
    Group() group.Group
    H1(data []byte) group.Scalar
    H2(data []byte) group.Scalar
    H3(data []byte) group.Scalar
    H4(msg []byte) []byte
    H5(data []byte) []byte
    HashToCurve(data []byte) (group.Element, error)
    Hash(data []byte) []byte
    VerifySignature(message []byte, signature []byte, publicKey group.Element) error
    ContextString() string
}
```

Defines the cryptographic primitives for a FROST instantiation.

### Hash Functions

- **H1**: Domain-separated hash for binding factor computation (maps to Scalar)
- **H2**: Domain-separated hash for signature challenge (maps to Scalar)
- **H3**: Domain-separated hash for nonce generation (maps to Scalar)
- **H4**: Domain-separated hash for message hashing (maps to bytes)
- **H5**: Domain-separated hash for commitment list hashing (maps to bytes)
- **Hash**: Underlying cryptographic hash function
- **HashToCurve**: Maps byte strings to group elements

### Supported Ciphersuites

#### FROST(ristretto255, SHA-512)

```go
import "github.com/jeremyhahn/go-frost/pkg/frost/ciphersuite/ristretto255_sha512"

suite := ristretto255_sha512.New()
```

**Ciphersuite ID:** `FROST-RISTRETTO255-SHA512-v1`

**Properties:**
- Group: ristretto255
- Hash: SHA-512
- Context String: "FROST-RISTRETTO255-SHA512-v1"

## Group Interface

### Group Interface

```go
type Group interface {
    Name() string
    Order() *big.Int
    Generator() Element
    Identity() Element
    RandomScalar() (Scalar, error)
    ScalarLength() int
    ElementLength() int
    NewScalar() Scalar
    NewElement() Element
    ScalarBaseMult(s Scalar) Element
    DeserializeScalar(data []byte) (Scalar, error)
    DeserializeElement(data []byte) (Element, error)
}
```

Defines operations on a prime-order group.

### Scalar Interface

```go
type Scalar interface {
    Add(other Scalar) Scalar
    Sub(other Scalar) Scalar
    Mul(other Scalar) Scalar
    Inv() (Scalar, error)
    Negate() Scalar
    Equal(other Scalar) bool
    IsZero() bool
    Bytes() []byte
}
```

Represents a scalar in the group's field.

### Element Interface

```go
type Element interface {
    Add(other Element) Element
    Sub(other Element) Element
    Mul(scalar Scalar) Element
    Negate() Element
    Equal(other Element) bool
    IsIdentity() bool
    Bytes() []byte
}
```

Represents an element in the prime-order group.

### Error Handling Examples

```go

// Check for specific error types

    log.Printf("Invalid parameter %s: %s", paramErr.Parameter, paramErr.Reason)

// Check for specific error conditions
```

## Constants

### Identifier Constraints

- Minimum identifier value: `1` (zero is invalid)
- Maximum identifier value: `2^32 - 1`

### Threshold Constraints

- Minimum MinSigners: `2`
- MinSigners must be <= MaxSigners

## Thread Safety

All service layer operations are thread-safe. Individual components (Participant, Aggregator) are designed for single-threaded use within a signing session.

## Performance Considerations

- **Key Generation**: O(n) where n is MaxSigners
- **Round One**: O(1) per participant
- **Round Two**: O(n) where n is number of signers
- **Aggregation**: O(n) where n is number of signature shares
- **Verification**: O(1)

For benchmarks, see [Testing Guide](testing.md).
